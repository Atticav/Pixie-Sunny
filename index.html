            Como configurar o provider local
            
            
            
              
            Modo Mock — nenhum servidor necessário. Gera imagens placeholder para testar o workflow de organização, histórico e uso de referências.
            
              
            API local (Automatic1111) — inicie o servidor com a flag --api:
            
              
            ./webui.sh --api --listen
            
              
            O endpoint padrão é http://127.0.0.1:7860. A integração usa a rota /sdapi/v1/txt2img.
            
              
            API local (ComfyUI) — ComfyUI usa WebSockets. Para compatibilidade simples, use um wrapper HTTP como comfyui-api ou adapte o endpoint.
            
              
            Dica para Mac: use stable-diffusion-webui no Terminal com o script webui.sh. Na primeira execução, baixa as dependências automaticamente.
